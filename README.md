# Made-máticas · Matemáticas para la madera

Apuntes y programa para sacar medidas y ángulos en carpintería y ebanistería con Pitágoras, trigonometría y la calculadora, sin abrir el CAD.

**Web:** https://eloiaa-hub.github.io/Made-maticas/

## Contenido

| Carpeta | Qué hay |
|---|---|
| `index.html` | Página principal |
| `programa/` | El programa (`index.html` + `assets/three.min.js`) y su guía en HTML y PDF |
| `apuntes/` | Los apuntes en HTML y PDF |
| `descargas/` | El programa en un zip para usarlo sin conexión |

## Programa

- **Practicar:** ejercicios al azar de 11 temas y 3 niveles, con dibujo, corrección, pista y solución paso a paso.
- **Ficha imprimible:** hojas con varias versiones y soluciones.
- **Explorar:** figuras con deslizadores e inglete compuesto en 3D.
- **Formulario.**

Para usarlo sin conexión, descarga `descargas/matematicas_madera.zip`, descomprímelo y abre `matematicas_madera.html`. La carpeta `assets` tiene que ir junto al HTML (la necesita la vista 3D).

## Apuntes

15 capítulos: Pitágoras, trigonometría, escaleras, ingletes y polígonos, arcos, radio de esquina, repartos, del taller a la CNC, cubiertas y cerchas, ingletes compuestos, arcos de carpintería, escaleras de caracol, cubicación y presupuesto, y un proyecto completo (un banco de jardín). Con errores típicos, formulario y soluciones.
